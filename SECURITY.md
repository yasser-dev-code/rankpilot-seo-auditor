# Security Policy

## Supported Versions

Security updates are provided for the latest stable release of RankPilot SEO Auditor.

| Version | Supported |
|---|---|
| Latest stable release | :white_check_mark: |
| Older releases | :x: |

Users are encouraged to upgrade to the latest stable version to benefit from security fixes and improvements.

## Reporting a Vulnerability

If you discover a security vulnerability in RankPilot SEO Auditor, please report it responsibly.

**Preferred reporting method:**

Use GitHub's Private Vulnerability Reporting feature through the repository's Security tab.

Please do not disclose security vulnerabilities publicly before they have been investigated and addressed.

### What to Include

When reporting a vulnerability, please provide:

- A clear description of the vulnerability.
- Steps to reproduce the issue.
- Potential security impact.
- Relevant screenshots, logs, or proof of concept, if available.

### Response Timeline

- Acknowledgment: Within 5 business days.
- Initial assessment: Within 14 calendar days.
- Further updates: Provided as the investigation progresses.

### What to Expect

If the vulnerability is accepted, we will investigate its impact and work on an appropriate security fix.

If the report is declined, we will provide an explanation where possible.

We appreciate responsible security research and the effort involved in helping keep RankPilot SEO Auditor secure.

Thank you for helping protect RankPilot SEO Auditor and its users.
